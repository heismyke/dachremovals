# Dach Removals Backend

Go API for the Dach Removals admin system.

## Run

```bash
go run ./cmd/api
```

Default address:

```text
http://localhost:8080
```

## Endpoints

- `GET /health`
- `POST /api/auth/login`
- `GET /api/quotes`
- `POST /api/quotes`
- `GET /api/bookings`
- `POST /api/bookings`
- `GET /api/messages`
- `POST /api/messages`
- `GET /api/content`
- `PUT /api/content`
